# SANAD AI V3

واجهة عربية RTL متجاوبة، مبنية باستخدام React + TypeScript + Vite، ومهيأة للنشر على Vercel.

## الخدمات الموجودة
- عين سند: وصف المشهد من الكاميرا واستخراج النصوص من الصورة عبر نموذج الرؤية.
- مساعد التواصل: تحويل الكلام العربي إلى نص عبر Web Speech API في المتصفحات الداعمة.
- أدوات الإتاحة: تكبير الخط، تباين عالٍ، أزرار واضحة، وأوامر صوتية للتنقل داخل الموقع.
- مساعد التعلّم: تبسيط النصوص وشرحها خطوة بخطوة.
- اسأل سند: محادثة نصية عربية.

## النشر
1. فك ضغط الملف وارفع محتوياته (المجلدات والملفات) إلى مستودع GitHub جديد أو فرع جديد. لا ترفع ملف ZIP وحده.
2. اربط المستودع بمشروع جديد في Vercel.
3. إعدادات البناء: Framework = Vite، Build Command = `npm run build`، Output Directory = `dist`.
4. في Vercel > Project > Settings > Environment Variables أضف `OPENAI_API_KEY`، ويمكن إضافة `OPENAI_MODEL` بقيمة `gpt-4.1-mini`.
5. أعد النشر بعد إضافة المتغيرات.

## حماية المفتاح
لا تضع مفتاح API في ملفات الواجهة أو GitHub ولا ترسله في المحادثات. المفتاح يُحفظ على الخادم في Vercel فقط. راجع إعدادات الاستخدام والتكلفة مع ولي أمرك أو مسؤول الموقع قبل تفعيل خدمة مدفوعة.

## حدود مهمة
- ميزات وصف الصور وقراءة النصوص والتبسيط والشرح والمحادثة تحتاج مفتاح API صالحًا في Vercel واتصالًا بالإنترنت.
- التعرف على الكلام يعتمد على دعم المتصفح واللغة وإذن الميكروفون، وقد لا يعمل في بعض المتصفحات أو الأجهزة.
- أوامر الصوت تنفذ تنقلًا داخل موقع سند فقط، ولا تتحكم في الهاتف أو التطبيقات الأخرى.
- لم يتم تضمين تسجيل دخول أو تخزين محادثات أو لوحة ولي أمر.
- لا تعتمد على وصف الكاميرا وحده للملاحة أو عبور الطرق أو الحالات الطارئة.
- هذه نسخة أولية متكاملة وظيفيًا وليست شهادة إتاحة أو ضمان دقة. اختبر كل ميزة مع مستخدمين فعليين وبمراجعة شخص بالغ مسؤول قبل إطلاقها للعامة.

## ملاحظة تقنية
المعالجة تمر عبر `/api/assistant` ولا يُرسل مفتاح API إلى المتصفح. أضف قبل الإطلاق العام حماية إضافية مثل rate limiting موثوق، مراقبة الاستخدام، وسياسة خصوصية واضحة.
